5. **No gradients, no glassmorphism, no neon glows, no drop shadows on text, no Tailwind `backdrop-blur`** on surfaces. The design system explicitly bans these (see §3). Flat hairlines, solid surfaces, solid gold accent (`#D4A574`).

## 3.5 Borders & dividers

- Default hairline: `1px solid var(--border-primary)` (`#242424`)
- Subtle divider: `1px solid rgba(255,255,255,0.06)`
- Focus ring: `2px solid var(--accent-primary)` with `2px` offset, never removed
- Corner radius: `sm 6px / md 10px / lg 14px / xl 20px / full 9999px`

## 3.6 Typography (three-register editorial)

- **Display** (serif): `'Playfair Display', Georgia, 'Times New Roman', serif` — H1, H2, hero
- **Body** (grotesque): system stack `-apple-system, BlinkMacSystemFont, 'Segoe UI', 'Helvetica Neue', Helvetica, Arial, sans-serif`
- **Mono** (data): `ui-monospace, 'SF Mono', 'JetBrains Mono', Consolas, monospace` — all counters, log lines, code, scores

Sizes: `xs 11 / sm 13 / base 15 / md 17 / lg 20 / xl 24 / 2xl 30 / 3xl 40 / 4xl clamp(44,7vw,96)` px. Display weight 700, body 400/500, mono 600. Line-height tight 1.15 / normal 1.5 / relaxed 1.7. Tracking tight -0.02em on display, wide 0.16em on mono uppercase labels.

## 3.7 Spacing

4px base: `0,1,2,3,4,6,8,12,16,24,32,48,64,96` (Tailwind scale covers this).

## 3.8 Motion (classic preset — refined, not bouncy)

- `--dur-instant 50ms`, `--dur-fast 150ms`, `--dur-normal 250ms`, `--dur-slow 400ms`, `--dur-slower 600ms`, `--dur-ambient 900ms`
- `--ease-default cubic-bezier(0.25,0.1,0.25,1)`, `--ease-out cubic-bezier(0,0,0.2,1)`, `--ease-cinematic cubic-bezier(0.22,1,0.36,1)`, `--ease-spring cubic-bezier(0.34,1.56,0.64,1)` (use sparingly)
- All animations wrapped in `@media (prefers-reduced-motion: reduce) { animation: none !important; }`
- Page transitions: crossfade + 6px slide, 250ms, both directions supported via `view-transition-name` (progressive enhancement — browsers without VT just snap)

## 3.9 Banned (will be rejected in review)

- ❌ Any CSS `linear-gradient` / `radial-gradient` on text or surfaces (a single 1px hairline conic is allowed only on a special "live" status pill)
- ❌ `backdrop-filter: blur()` (no glassmorphism)
- ❌ `text-shadow` (no text glow)
- ❌ `box-shadow` with color (only neutral `0 1px 2px rgb(0 0 0 / 0.3)` is allowed, never colored)
- ❌ Neon, glitch, chrome, iridescent, holographic effects
- ❌ Animated background videos
- ❌ More than 2 font families

# 10. 7-LAYER VALIDATION ENGINE

Implement in `apps/api/app/validator/`. Mirror types in `packages/contracts/src/index.ts`.

For each layer: pure function `(input, context) -> LayerResult`, deterministic per email (use FNV-1a hash + Mulberry32 PRNG) so the demo behaves like a real backend: same address → same verdict, every time. Layers:

1. **Syntax** — RFC 5322 regex, max length 320
2. **DNS** — `dns.resolver.resolve` (A/AAAA/NS), reject NXDOMAIN, detect typo via TYPO_MAP and return `did_you_mean`
3. **MX** — `dns.resolver.resolve(domain, 'MX')`, reject null-mx, return priority-sorted hosts
4. **Disposable** — membership in `disposable_domains` table (admin-managed) + small built-in seed (mailinator.com, tempmail.io, guerrillamail.com, 10minutemail.com, yopmail.com, trashmail.com, sharklasers.com, getnada.com, temp-mail.org, maildrop.cc, dispostable.com, fakeinbox.com)
5. **Catch-All** — SMTP `RCPT TO` probe to a random non-existent local part; if accepted, mark `catchall=true`
6. **SMTP** — full handshake (HELO/EHLO, MAIL FROM, RCPT TO, QUIT) on port 25 with timeout 5s; return `pass | fail (550) | warn (451 greylist) | unknown (timeout/blocked)`
7. **ML Scoring** — weighted sum of signals: deliverable (0.40), domain age (0.10), free provider (0.05), role local (0.05), disposable (0.20), catch-all (0.20) → 0-100

Return shape:
```ts
type LayerKey = 'syntax'|'dns'|'mx'|'disposable'|'catchall'|'smtp'|'scoring';
type LayerStatus = 'pass'|'fail'|'warn'|'skip'|'off';
interface LayerResult { key: LayerKey; name: string; status: LayerStatus; ms: number; note: string }
type VerdictStatus = 'valid'|'invalid'|'risky';
interface Verdict {
  email: string; domain: string; score: number; status: VerdictStatus; action: string;
  layers: LayerResult[]; total_ms: number;
}
```

Rules:
- Score < 40 → `invalid`, action `"Do not send — hard bounce likely"`
- 40 ≤ Score < 75 → `risky`, action `"Manual review — route to human"`
- Score ≥ 75 → `valid`, action `"Safe to send"`

A web-side mirror in `apps/web/src/lib/engine.ts` provides an **offline demo mode** when `VITE_OFFLINE_DEMO=true` so the UI works without the API. It must produce identical verdicts to the backend for the same email (because the same seed → same verdict). In offline mode, `smtp` layer is always `unknown` and the verdict defaults to `risky` with a UI note.
